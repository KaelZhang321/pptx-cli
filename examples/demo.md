## Welcome to pptx-cli

A powerful CLI tool that converts Markdown to PowerPoint presentations.

---

## Features

- Simple Markdown syntax
- Multiple templates
- Easy to customize
- Fast and efficient

---

## Getting Started

1. Install pptx-cli
2. Write your slides in Markdown
3. Run pptx-cli generate
4. Share your presentation!
